# A-Dos Alpha v1.3 — 4명 파일 공유 테스트 패키지

> **중요: ChatGPT 연동은 아직 동작하지 않습니다.** 이 프로젝트는 실제 업로드와 공유 텍스트 검색을 테스트하는 임시 서버입니다. OpenAI Sign in with ChatGPT의 원격 호스팅 사용 승인이 없으므로 개인 구독 한도 추론은 비활성화되어 있습니다. **별도 API 과금 또는 자동 API 전환도 없습니다.**

## 현재 테스트 가능한 기능

- 첫 로그인 화면에 1페이지 알파테스터 안내창 표시, 모바일 대응
- 테스트 계정 `tester1`, `tester2`, `tester3`, `tester4` (개발 환경의 초기 비밀번호 `alpha1234`)
- Node 서버 실행 시 4개 계정이 같은 `CES 2027` 프로젝트에 자료 업로드/목록 공유
- 업로드한 원본 파일을 서버 디스크에 저장 및 다운로드 (파일당 최대 10 MB)
- `TXT`, `MD`, `CSV`: 서버에서 텍스트 추출·공유 및 **원문 관련 구절 검색** (Question)
- `PDF`, `PPTX`, `DOCX`, 이미지: 업로드·다운로드 가능하지만 아직 텍스트 추출 및 AI 분석 불가
- 다른 프로그램은 원래 프로토타입 시연 모드 (개인 로컬 브라우저 데이터)

**실제 AI 질문/답변은 아닙니다.** Question의 공유 자료 검색은 문장에서 겹치는 단어를 찾아 원문을 인용하는 기능입니다. ChatGPT 인증 성공, AI 추론, 파일 의미 분석 등을 표시하거나 약속하지 않습니다.

## 로컬 실행 (Node.js 20 이상)

```bash
node server.js
```

브라우저에서 `http://localhost:4173` 접속. 같은 네트워크의 다른 기기는 실행 PC의 LAN IP로 접속할 수 있지만, **외부 인터넷에 그대로 공개하지 마세요.** 기본 테스터 비밀번호가 공개되어 있으며 실제 회사 문서나 개인 정보를 넣으면 안 됩니다.

서버 공유 파일은 `data/uploads/`, 파일 목록은 `data/records.json`에 저장됩니다. 서버를 재시작해도 파일은 유지되지만 세션은 초기화됩니다. 이 저장 경로는 백업·보안 용도가 아니며 테스트 전용입니다.

### 환경 변수

`PORT`: 기본 4173
`ADOS_DATA_DIR`: 서버가 파일을 저장할 경로 (영속 디스크 필수)

공개 접근 가능한 환경에서 실행할 경우 최소한 아래 값을 설정하세요.

```bash
NODE_ENV=production
ADOS_ALPHA_PASSWORD=(자체 설정한 길고 랜덤한 비밀번호)
ADOS_ADMIN_PASSWORD=(자체 설정한 서로 다른 관리자 비밀번호)
```

서버는 production 모드에서 두 비밀번호 환경 변수가 없으면 시작되지 않습니다. TLS(HTTPS) 역방향 프록시와 접근 허용 제한도 별도로 필요합니다. 데모의 브라우저 로컬 로그인은 보안 계정이 아니므로, 이 패키지를 민감 자료용 운영 서비스로 사용해서는 안 됩니다.

## GitHub Pages로 배포하면?

`index.html`만 업로드하면 **첫 화면 안내 + 각 기기별 브라우저 시연**만 됩니다. Github Pages는 Node 서버를 실행하지 않으므로 파일 공유 및 원문 검색 API는 동작하지 않습니다. 4명 공동 테스트를 하려면 Node 서버를 실행할 수 있는 호스팅과 지속 저장소가 필요합니다.

## 실제 ChatGPT 계정 연결까지 필요한 사항

1. OpenAI의 Sign in with ChatGPT에서 **원격 호스팅 앱 사용 승인**.
2. 각 사용자의 OAuth 로그인, 권한 동의 및 `chatgpt.tokens.use.direct` 범위 검증.
3. 토큰 검증/갱신 및 암호화된 서버 저장. **토큰을 localStorage·GitHub 코드·로그에 남기지 않기**.
4. 서버에서 보호된 액세스 토큰으로 지원되는 Responses API 요청, 사용자별 사용량 제한 및 유료 API 자동 전환 차단.
5. 승인된 범위에서만 AI 모드를 활성화하고, 내부 파일 검색(자체 검색)으로 가져온 문서를 AI에 전달해 출처 표시.
6. 4명 고유 인증 및 파일 접근 권한을 서버에서 강제하는 운영용 백엔드 전환.

참고: https://developers.openai.com/siwc/token-sharing-open-source

## 알파테스터 안내

첫 화면 안내창은 페이지에 포함되어 있습니다. 계정 정보는 **시연용이며 실제 보안 인증이 아님**을 반복 고지합니다.

테스트 순서: 로그인 → Projects → CES 2027 → Files → `.txt` 업로드 → Question에서 해당 파일에 들어있는 구절 질문 → 다른 테스터 계정에서 목록 및 검색 확인.

관리자가 쓰는 실제 프로젝트 기밀 자료는 업로드하지 마세요.
